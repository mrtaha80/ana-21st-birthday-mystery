# جهانِ کوچکِ طاها و آنا

وب‌اپ فارسی، راست‌چین و واکنش‌گرا برای قصه‌ها و قرارهای مشترک: داشبورد، خط زمان، اطلس نمادین، صندوق عکس، نامه‌های تاریخ‌دار، حالت آرام و بازی‌ها.

## اجرا

```bash
npm install
npm run dev
```

## دیتابیس دونفره (اختیاری)

1. در پروژه‌ی Supabase فقط دو حسابِ Auth بسازید و ثبت‌نام عمومی را خاموش نگه دارید.
2. `sql/setup.sql` را در SQL Editor اجرا کنید؛ UUID دقیق همین دو حساب را در دستور insert انتهای فایل جایگزین کنید.
3. `.env.example` را به `.env.local` کپی کنید و Project URL، publishable/anon key و ایمیل ورود طاها را وارد کنید. کلید `service_role` یا secret را هرگز در مرورگر یا GitHub نگذارید.
4. `npm run dev` را دوباره اجرا کنید. ورودِ دونفره، همگام‌سازی JSON با RLS و پرس‌وجوی تغییرها هر ۸ ثانیه آماده‌اند.
5. برای انتشار، متغیرهای عمومی را در میزبان HTTPS تنظیم و دوباره build/deploy کنید. پروژه‌ی Supabase، دو حساب و هاست را مالک پروژه باید بسازد؛ اطلاعاتِ ورود در این مخزن نیست.

RLS جدول را فقط برای UUIDهای `couple_members` باز می‌کند. در این نسخه عکس‌ها فشرده و داخل payload محافظت‌شده‌ی همان دو حساب همگام می‌شوند؛ با تعداد عکس زیاد ممکن است محدودیت اندازه‌ی ردیف/حافظه برسد. باکت خصوصیِ SQL برای مهاجرت آینده آماده است اما این رابط از آن استفاده نمی‌کند.

بدون Supabase برنامه فقط در مرورگر فعلی ذخیره می‌شود؛ بین گوشی‌ها همگام نیست. آب‌وهوای زنده و نقشه‌ی مسیریاب پیاده نشده‌اند. نامه‌های تاریخ‌دار قفل تقویمیِ نمایشی دارند و متن رمزنگاری نمی‌شود؛ چیزهای حساس ننویسید.

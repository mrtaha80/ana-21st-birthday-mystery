# پرونده‌ی ۲۱ سالگی آنا

یک تجربه‌ی تعاملی و فارسی برای تولد ۲۱ سالگی آنا: سه معمای کوتاه با تم گورخر، کروکدیل و سفر طاها به اصفهان، و یک نامه‌ی پایانی.

## اجرا

در محیطی که Node.js نصب است:

```bash
npm install
npm run dev
```

## ویژگی‌ها

- فارسی، راست‌چین و واکنش‌گرا برای موبایل و دسکتاپ
- بدون شمارش معکوس، صدای خودکار یا اجبار به تکمیل
- ذخیره‌ی پیشرفت روی همان دستگاه با `localStorage`
- کلید «حالت آرام» برای حذف انیمیشن‌ها و حرکت‌های تزئینی
- امکان شروع دوباره از پایین صفحه

متن نامه و نشانه‌ها را می‌توان در `src/App.jsx` شخصی‌سازی کرد.

# جهانِ کوچکِ طاها و آنا

وب‌اپ فارسی و راست‌چین برای نگه‌داشتنِ قصه‌ها و قرارهای مشترک: داشبورد، خطِ زمان، اطلسِ نمادین، صندوقِ خاطره، نامه‌های تاریخ‌دار، بازی‌ها، QR هدیه و حالتِ آرام.

## اجرا

```bash
npm install
npm run dev
```

ساخت: `npm run build` · پیش‌نمایش: `npm run preview`.

## ذخیره و حریم خصوصی

- پیش‌نمایش هیچ فرمِ ورود یا گذرواژه‌ای ندارد و به هیچ API دیتابیسی وصل نمی‌شود.
- خاطره‌ها روی همان مرورگر با `localStorage` می‌مانند؛ بین دو گوشی همگام نیستند.
- عکس‌ها فشرده می‌شوند و فقط در همین مرورگر ذخیره می‌شوند.
- نامه‌ها قفلِ تقویمیِ نمایشی دارند، نه رمزنگاری‌شده؛ اطلاعات حساس ننویسید.
- `sql/setup.sql` فقط یک طرحِ پایه‌ی RLS برای پیاده‌سازیِ آینده است؛ خودکار اجرا نمی‌شود و این اپ از آن استفاده نمی‌کند. برای سرویس مشترک باید بک‌اندِ خصوصی و حساب‌های مجاز را جداگانه راه‌اندازی کنید؛ این مخزن هیچ کلید، رمز یا دیتابیس فعالی ندارد.
- `.env.example` مصرفی در نسخه‌ی فعلی ندارد. هرگز `service_role` یا گذرواژه را در مرورگر یا GitHub نگذارید.

هوای زنده و نقشه‌ی مسیریابی وصل نیستند.

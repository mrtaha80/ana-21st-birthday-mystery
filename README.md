# جهانِ کوچکِ طاها و آنا

وب‌اپ فارسی، راست‌چین و واکنش‌گرا برای قصه‌ها و قرارهای مشترک. شامل داشبورد، خط زمان، اطلس نمادین، صندوق خاطره، نامه‌های تاریخ‌دار، یادداشت آرامش، بازی و QR تولد.

## اجرا

```bash
npm install
npm run dev
```

## فعال‌کردن دیتابیس مشترک Supabase

1. یک پروژه بساز و فقط دو کاربر را از داشبورد Supabase در Authentication ایجاد کن. ثبت‌نام عمومی را فعال نکن.
2. `sql/setup.sql` را در SQL Editor اجرا کن. از Authentication → Users شناسه‌ی UUID دو حساب را بگیر، دستور insert انتهای فایل را با همان دو UUID کامل کن و اجرا کن.
3. `.env.example` را به `.env.local` کپی کن و URL پروژه، publishable/anon key و ایمیل ورود طاها را بنویس. فقط کلید عمومی مجاز است؛ **هرگز service_role/secret key را در متغیر VITE یا کد مرورگر قرار نده.**
4. سرور توسعه را دوباره راه‌اندازی کن. ورود با یکی از دو حساب فعال می‌شود؛ محتوای مشترک از Postgres می‌آید و فایل‌ها در Storage خصوصی ذخیره می‌شوند.
5. برای استقرار عمومی، همین سه متغیر عمومی را به سرویس HTTPS خودت اضافه و build را دوباره منتشر کن. حساب میزبان/Supabase یا دامنه از این مخزن ساخته نشده‌اند.

سیاست‌های RLS در SQL جدول مشترک و فضای عکس را به UUIDهای درج‌شده در `couple_members` محدود می‌کنند. SQL را پیش از اجرا بازبینی کن. کلید `anon` عمومی است و جای RLS را نمی‌گیرد.

بدون متغیرهای Supabase، برنامه فقط روی همین مرورگر ذخیره می‌کند. همگام‌سازی، ورود ابری، live weather و نقشه‌ی مسیریابی تا زمان تنظیم سرویس در دسترس نیستند. نامه‌ی تاریخ‌دار قفلِ نمایشی دارد، نه رمزنگاری‌شده؛ اطلاعات خیلی حساس ننویسید.
